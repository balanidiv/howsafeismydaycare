How safe is my daycare?
How this works Div Balani
Methodology

Public records, one search box.

Texas already publishes child-care licensing, inspections, and deficiencies. Parents should not have to learn a state portal to read them. This site queries the official datasets live and puts a derived safety grade on top so a hiring manager — or a parent — can see the product judgment, not just a CSV dump.

Where the data comes from

Texas Health and Human Services Commission, Child Care Licensing, via the Texas Open Data Portal (Socrata). No scrape. No third-party grade vendor.

  • Operations — license, capacity, status, deficiency counts
  • Inspections / investigations / assessments
  • Non-compliance (deficiencies)

Included operation types: Licensed Center, Licensed Child-Care Home, Registered Child-Care Home, Listed Family Home. Excluded: general residential operations and child-placing agencies.

How the letter grade is computed

This is not an official HHSC rating. It is a transparent score so you can compare files quickly.

SignalEffect
Start100
Each High deficiency−12
Each Medium High−7
Each Medium−4
Each Medium Low−2
Each Low−1
Adverse action−20
Corrective action−10
Inactive or temporarily closedNo letter — marked closed

A ≥ 90, B ≥ 80, C ≥ 70, D ≥ 60, F below. Recent inspections are listed in full so you can ignore the letter and read the file.

Limits

  • Texas only. This ship does not include any other state.
  • A clean file is not a promise. Inspectors miss things. Directors fix things after the visit.
  • Do not use this instead of a tour, references, or your state licensing office.
